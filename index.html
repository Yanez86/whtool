Aggregatore giacenze

Un file di giacenza UdC diventa un riepilogo per articolo.

  • Raggruppa per articolo, descrizione, stato contabile e data scadenza
  • Somma la quantità stoccata e conta le UdC
  • Puoi aggiungere qualsiasi altro campo del file

Inventario

Dalla giacenza UdC alla lista di spunta con barcode.

  • Lista picking ordinata per scaffale, lato, campata e piano
  • Barcode Code 39 disegnati: nessun font da installare
  • Foglio di controllo corridoi SX/DX con colonna spuntatore

Spacchetta borderò

Un PDF scansionato di borderò diventa un file per viaggio.

  • OCR della testata nel browser, nessun caricamento online
  • Un PDF per ogni coppia azienda + viaggio, allegati inclusi
  • Download in ZIP e mappa CSV pagina → pacchetto
Apri il tool →

Formati letti: .xlsx, .xlsm, .xls, .csv e PDF. Al primo caricamento serve la connessione a internet per scaricare le librerie; lo spacchetta borderò scarica anche i dati lingua dell'OCR (circa 15 MB, poi restano in cache).
